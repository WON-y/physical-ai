## 요약

**COCO로 사전학습된 YOLO26 모델을 person·helmet·vest·head 4개 클래스로 파인튜닝해서 단일 모델로 쓴다.** 모델 크기는 n·s·m을 같은 조건으로 학습한 뒤 고르고, 1순위 후보는 YOLO26s다. 선택 기준은 Jetson Orin NX(TensorRT FP16)에서 15 FPS 이상을 내는 모델 중 val 정확도가 가장 높은 것이다.

| 구분        | 결정                                                                                                 |
| ----------- | ---------------------------------------------------------------------------------------------------- |
| 모델        | YOLO26 n·s·m 중 선정 (후보 s). 프레임당 추론 1회                                                   |
| 학습 방식   | COCO`yolo26?.pt`에서 시작하는 파인튜닝. 특징 추출부는 그대로 가져오고 출력층은 4클래스로 새로 학습 |
| 클래스      | person, helmet, vest, head (head = 안전모를 쓰지 않은 머리)                                          |
| person 라벨 | 원래 라벨이 없는 데이터는 COCO 모델로 자동 라벨링. test셋은 사람이 검수                              |
| 데이터      | Construction-PPE로 시작 → Hard Hat Workers·AIHub 보호구 클래스로 확장 → 자체 현장 데이터로 마무리 |
| 검증 1      | test셋 검출 성능: 클래스별 P·R·mAP50·mAP50-95, 조건별(거리·조도) 결과                            |
| 검증 2      | 사람 단위 착용 판정: 포함률 규칙, 미착용 Recall ≥ 0.95 / Precision ≥ 0.90                          |
| 최종        | Jetson 영상 이벤트 테스트: 연속 5프레임 확정, 오탐 ≤ 3건/로봇/일                                    |

## 적합한 모델

YOLO26 n·s·m을 같은 조건으로 파인튜닝해서 비교한다. l·x는 Jetson Orin NX에서 15 FPS를 맞추기 어려워 제외한다.

| 모델    | COCO mAP50-95 | T4 TensorRT (ms) | 역할             |
| ------- | ------------- | ---------------- | ---------------- |
| YOLO26n | 40.9          | 1.7              | 기준선           |
| YOLO26s | 48.6          | 2.5              | 1순위 후보       |
| YOLO26m | 53.1          | 4.7              | 정확도 상한 확인 |

**선정 기준**: Jetson에서 15 FPS 이상인 모델 중 val 정확도가 가장 높은 것을 고른다. 두 모델의 차이가 작으면(mAP50 0.01 이내) 더 작은 모델을 고른다. 사람과 보호구를 한 모델에서 함께 검출하므로 추론은 프레임당 1회만 한다.

## 파인튜닝 설계

COCO 사전학습 모델의 특징 추출부는 그대로 가져오고, 출력층은 4클래스로 새로 학습한다. 학습 데이터에 라벨이 없는 클래스는 결과 모델에서 사라지므로 person도 함께 학습한다.

| 클래스 | 역할                                                                                      |
| ------ | ----------------------------------------------------------------------------------------- |
| person | 착용 판정의 기준이 되는 박스                                                              |
| helmet | 머리 영역에 있으면 착용                                                                   |
| vest   | 상체 영역에 있으면 착용                                                                   |
| head   | 안전모 없는 머리. 미착용의 직접 증거가 되어 '안전모를 못 찾음'과 구분되므로 오탐이 줄어듦 |

## 학습 데이터

| 데이터셋                                                                                                                     | 이미지 수  | 용도                                               |
| ---------------------------------------------------------------------------------------------------------------------------- | ---------- | -------------------------------------------------- |
| [Construction-PPE](https://docs.ultralytics.com/datasets/detect/construction-ppe/)                                            | 1,416      | 베이스라인 (person·helmet·vest·no_helmet 포함)  |
| [Hard Hat Workers](https://universe.roboflow.com/joseph-nelson/hard-hat-workers)                                              | 7,035      | helmet·head 보강                                  |
| [AIHub 공사현장 안전장비](https://aihub.or.kr/aihubdata/data/view.do?currMenu=115&topMenu=100&aihubDataSe=data&dataSetSn=163) | 약 203만   | 보호구 클래스가 있는 이미지만 골라 보강용으로 사용 |
| 자체 현장 데이터                                                                                                             | 2,000 이상 | 최종 학습·검증                                    |

- person 라벨이 없는 데이터는 COCO 모델로 자동 라벨링하고, test셋 라벨은 사람이 검수한다.
- train/val/test(70/15/15)는 학습 전에 현장·영상 단위로 나눈다.

## 학습 절차

1. **베이스라인**: YOLO26n과 Construction-PPE로 학습부터 착용 판정까지 한 번 끝까지 돌려 본다.
2. **데이터 확장**: Hard Hat Workers와 AIHub 데이터를 더해 val 성능이 오르는지 본다.
3. **크기 비교**: n·s·m을 같은 설정(epochs 100, imgsz 640, seed 0)으로 학습하고 Jetson에서 FPS를 잰다.
4. **현장 적응**: 고른 모델을 자체 현장 데이터로 한 번 더 파인튜닝한다.

```python
from ultralytics import YOLO

model = YOLO("yolo26s.pt")
model.train(data="ppe.yaml", epochs=100, imgsz=640, seed=0)
```

## 전체 흐름

**A. 검출 모델 (person·helmet·vest·head)**

1. 데이터·클래스 확정: 4클래스 정의, 데이터셋 통합, 라벨 기준 문서 작성
2. 데이터 분할: 현장·영상 단위로 train/val/test 분리
3. n·s·m 비교 선정: val mAP와 Jetson FP16 15 FPS 이상
4. 검출 검증표: test셋 1회 평가, 클래스별 P·R·mAP

**B. 착용 판정 (포함률 규칙 엔진)**

5. 판정 테스트셋: 사람 단위 착용 라벨, 미착용 30% 이상
6. 임계값 조정: val셋으로 포함률 임계값 결정
7. 판정 검증표: test셋 1회 평가, 미착용 Recall·Precision
8. 영상 이벤트 테스트: Jetson에서 연속 5프레임 확정, 오탐 ≤ 3건/일

## 검증 1: 검출 성능

선정한 모델을 test셋으로 한 번만 평가한다 (`model.val(split="test")`).

| 클래스 | Precision | Recall | mAP50 | 목표           |
| ------ | --------- | ------ | ----- | -------------- |
| person |           |        |       | Recall ≥ 0.97 |
| helmet |           |        |       | mAP50 ≥ 0.93  |
| vest   |           |        |       | mAP50 ≥ 0.90  |
| head   |           |        |       | 참고용         |

Jetson에서 TensorRT FP16으로 변환한 뒤 mAP 하락(0.01 이내)과 FPS(15 이상)도 확인한다.

## 검증 2: 착용 판정

보호구 박스가 사람 박스의 해당 영역에 들어간 비율(포함률 = 겹친 면적 ÷ 보호구 박스 면적)로 착용 여부를 판단한다. 안전모 박스는 사람 박스보다 훨씬 작아서 IoU는 쓰지 않는다.

| 항목     | 영역                       | 착용 조건                       |
| -------- | -------------------------- | ------------------------------- |
| 안전모   | 사람 박스 상단 25%         | helmet 포함률 ≥ 0.6, head 없음 |
| 안전조끼 | 사람 박스 높이 20~65% 구간 | vest 포함률 ≥ 0.5              |

- 임계값은 val셋으로 정하고, test셋은 마지막에 한 번만 쓴다.
- 판정 테스트셋은 사람 1명마다 착용/미착용 정답을 단다. 사람 500명 이상, 그중 미착용 30% 이상으로 구성한다.
- 목표는 미착용 Recall ≥ 0.95, Precision ≥ 0.90이다.
- 마지막으로 Jetson에서 영상으로 테스트해, 오탐이 로봇 1대당 하루 3건 이하인지 확인한다.
