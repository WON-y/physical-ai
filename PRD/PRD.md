PRD: 건설현장 보호구 착용 점검 로봇 (PPE Compliance Inspection Robot)

문서 버전 v1.1 / 작성 기준일 2026-10-06
변경 사항: 범위를 "작업자의 안전장비(보호구) 착용 여부 점검" 으로 한정했다. 개구부·중장비 근접·화재·적치물 감지는 제외했다.
표기 규칙: 입력이 부족해 임의로 설정한 값에는 (가정) 을 표시한다.

1. 문제 정의 (Problem Statement)
1.1 현재 존재하는 문제
건설현장 사고에서 보호구 미착용은 반복적으로 지적되는 원인이다. 특히 안전모 미착용은 추락·낙하물 사고 시 두부 중상으로 이어진다.
대형 현장(동시 작업 구역 10곳 이상 (가정))에서는 안전관리자 2~3명 (가정) 이 모든 작업자의 착용 상태를 상시 확인할 수 없다.
미착용은 "잠깐 벗은 상태", "순찰자가 지나간 직후" 같은 짧은 시간 창에 발생하므로 정기 순찰로는 놓치기 쉽다.
1.2 기존 방식의 한계
기존 방식	한계
안전관리자 도보 순찰	순찰 사이 공백 발생, 관리자 가시권 밖 구역은 점검 불가, 기록이 수기
현장 출입구 게이트 점검	출입 시점에만 확인 가능, 작업 중 탈착은 확인 불가
고정식 CCTV	사각지대, 공정 진행에 따라 설치 위치 변경 필요, 사람이 직접 보지 않으면 무용
스마트 안전모(센서 내장)	모든 안전모를 교체해야 하고 조끼 등 다른 보호구는 확인 불가, 단가 부담
1.3 핵심 가치
이동형 상시 점검: 로봇이 현장을 순찰하며 작업자 착용 상태를 반복 확인해 사각지대를 줄인다.
즉시 알림과 증빙: 미착용 감지 후 3초 이내에 위치·시각·증빙 사진과 함께 관리자에게 전달한다.
현장 즉시 경고: 로봇이 해당 작업자 인근에서 음성·경광등으로 착용을 직접 안내한다.
착용률 데이터화: 구역·시간대·협력사별 착용률 통계로 안전교육 대상을 정할 수 있다.
1.4 왜 AI가 필요한가
안전모·조끼의 색상, 형태, 착용 각도, 역광·분진·비 조건이 다양해 규칙 기반 영상 처리(색상 필터 등)로는 안정적인 판별이 어렵다.
"사람이 있고 머리 위치에 안전모가 없다", "상체에 고시인성 조끼가 없다" 같은 판단은 사람 검출과 보호구 검출을 공간적으로 연결하는 딥러닝 객체 인식이 필요하다.
영상을 서버로 전부 보내면 지연과 통신비가 커지므로 Edge AI로 로봇 내부에서 추론하고 이벤트만 전송한다.
2. 사용자 시나리오 (User Scenario)

페르소나: 김 안전관리자, 대형 아파트 신축 현장, 담당 구역 12개 (가정)

단계	구분	내용
1단계	설치	관리자가 웹 대시보드에 현장 도면을 업로드한다. 로봇을 수동 조종해 순찰 경로를 1회 주행하며 웨이포인트를 저장한다. 점검 대상 보호구(안전모, 조끼)와 점검 시간대(예: 07:00~18:00)를 설정하고 충전 도크와 5G/LTE 라우터를 설치한다. 소요 시간은 현장당 약 1일 (가정).
2단계	데이터 수집	로봇이 설정된 경로를 자율 주행하며 PTZ RGB 카메라로 실시간 영상을 입력받는다 (1080p, 15 FPS 이상). 구역 웨이포인트마다 정지하여 좌우 스캔 후 이동한다. LiDAR는 주행과 장애물 회피 전용이다.
3단계	분석	로봇 내부 Edge AI가 프레임마다 ① 작업자(person) 검출 ② 안전모·안전조끼 검출 ③ 작업자별 추적 ID 부여 ④ 작업자 머리 영역(상단 25% (가정)) 안의 안전모 유무와 상체 영역의 조끼 유무를 판정한다. 작업자까지 거리는 3~10m (가정) 범위의 영상만 판정 대상으로 삼아 원거리 오판을 줄인다.
4단계	판단 결과 생성	동일 추적 ID에서 미착용이 연속 5프레임 이상 (가정) 유지되면 "미착용 이벤트"로 확정한다. 등급은 안전모 미착용 = 경고, 조끼 미착용 = 주의, 둘 다 미착용 = 경고로 한다. 이벤트에는 유형, 신뢰도, 지도상 위치, 증빙 이미지(박스 표시, 얼굴 블러 처리)를 포함한다. 같은 작업자·같은 위치의 중복 알림은 10분간 (가정) 억제한다.
5단계	제어	① 로봇이 해당 작업자 2~3m 앞에서 정지한다. ② 로봇의 경광등을 점등하고 스피커로 "안전모를 착용해 주세요" 안내 방송을 송출한다. ③ 이벤트를 MQTT로 서버에 전송하고 관리자에게 알림을 발송한다. ④ 30초 후 재촬영하여 착용으로 바뀌었는지 확인하고 순찰을 재개한다.
6단계	후속 행동	관리자는 문자·카카오 알림톡 링크나 웹 푸시로 이벤트를 받고, 대시보드에서 증빙과 위치를 확인한다. 재촬영 결과가 "착용 확인"이면 자동 종결되고, 미개선이면 관리자가 현장에서 직접 시정 지시를 하고 상태를 "확인 → 조치중 → 조치완료" 로 기록한다. 주간 리포트의 구역별·시간대별 착용률을 TBM(작업 전 안전회의) 교육 자료로 활용한다.

5. 개발 범위 / 비범위 (Scope)
5.1 개발 범위 (In Scope)
실시간 객체 인식: 작업자, 안전모, 안전조끼 검출 (Edge AI)
착용 판정 로직: 작업자 머리·상체 영역과 보호구 위치 관계로 착용 여부 판정, 추적 ID 기반 연속 프레임 확정
자율 순찰 주행: 웨이포인트 기반 반복 순찰, 장애물 회피, 자동 충전 도크 복귀
장치 제어: 미착용 작업자 인근 정지, 로봇 경광등·스피커 경고 방송, 30초 후 재촬영 확인
관리자 알림 기능: 문자/카카오 알림톡/웹 푸시로 위치·등급·증빙 전송, 미확인 시 재알림 1회
데이터 저장: 이벤트 메타데이터(DB)와 증빙 이미지(S3) 저장, 얼굴 블러 처리
관리자 웹 대시보드: 로봇 상태, 이벤트 목록, 조치 상태 관리(확인→조치중→조치완료), 구역별 착용률 조회
로그 저장 및 리포트: 시스템·추론·알림 발송 로그, 일간/주간 착용률 리포트 자동 생성
오프라인 버퍼링: 네트워크 단절 시 로컬 저장 후 복구 시 재전송
OTA 업데이트: 소프트웨어와 AI 모델 원격 배포
5.2 개발 제외 범위 (Out of Scope)
안전모·조끼 외 보호구 점검: 안전화, 안전장갑, 보안경, 안전대(하네스) 체결 여부는 2차 개발
환경 위험 감지: 개구부, 중장비 근접, 화재·연기, 통로 적치물 등
작업자 개인 식별(얼굴 인식): 개인정보 이슈로 제외, 위치·시각 기준으로만 기록
현장 고정 경광등·사이렌 연동: 로봇 자체 경고만 제공
음성 인식 및 대화 기능: 사전 녹음된 경고 방송만 송출
모바일 앱 개발: 문자·알림톡·웹 푸시와 반응형 웹으로 대체
다국어 지원: 한국어 경고 방송만 지원 (외국인 근로자용은 2차 개발)
클라우드 기반 자동 재학습: 재학습은 분기 1회 수동 수행
정교한 사용자 권한 관리(RBAC): 관리자/조회자 2단계만 제공
계단·사다리 주행: 평지와 완만한 경사로만 주행
